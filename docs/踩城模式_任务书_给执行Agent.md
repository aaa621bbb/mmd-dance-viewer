# 任务：给 mmd-dance-viewer 新增「踩城」游戏模式

仓库（public）：`https://github.com/aaa621bbb/mmd-dance-viewer`

**第一步不是写代码，是读规范。** clone 下来读 `docs/踩城模式_方案_v2.0.md`（raw 也可：
`https://raw.githubusercontent.com/aaa621bbb/mmd-dance-viewer/main/docs/%E8%B8%A9%E5%9F%8E%E6%A8%A1%E5%BC%8F_%E6%96%B9%E6%A1%88_v2.0.md`）。
这份规范的前情是：已经有 Agent 做完了现场勘查与实测（PMX 在 babylon-mmd 里的真实尺度、现成可复用接口、每一处要改的点），**所有数值都写死了**。你的任务是**高质量地执行**，不是重新规划。

## 这道题的分量在这三处

1. **尺度系统**：唯一常量 `PH`，全局禁裸数字。缩世界，**绝不缩放导入的 PMX**（她的 `scaling` 永远 = 1，缩了一秒崩）。
2. **碰撞**：自建格网哈希 + AABB 世界（分轴滑行、台阶、支撑面取 AABB 顶面、隐形边界、她的腿用胶囊推开）。
   必须写成**纯函数模块**，并在 Node 里跑单测：穿墙 / 卡角 / 上台阶 / 随机游走 10 万步不出界 —— **全绿才算过**。
3. **她的动作**：**不许向用户索要任何动作、模型、贴图、音频资源，一个字都不许问。**
   - 动作要你自己造：写一个 VMD 生成器（`tools/gen-motion.mjs`），注意 VMD 是二进制格式、骨骼名用 MMD 原名（`左足首/右足首/左つま先` 等）、注意贝塞尔插值参数，离线烘焙出 `idle / walk / stomp` 三段**自然**步态并入库。
   - 若你坚持上网找现成动作，只允许明确 CC0 / 可商用许可的，并把许可写进 `docs/`。
   - 必须做「**支撑脚接地驱动根位移**」（用脚骨世界坐标反向补偿根节点位移）—— 走路滑步（太空步）就是不及格。

## 纪律（违反即退回）

- **分步 push**：每完成一块就 commit + push，**一次 push = 一个说得清的进展**。禁止"全做完才推一次"。
- 前端改完必须 `cd frontend && node build.mjs && node deploy-to-apk.mjs`，并把 `app/src/main/assets/dist/main.js` **一起提交**。
  （CI 只跑 `./gradlew assembleDebug`，不构建前端 —— 不提交产物 = APK 里跑的还是旧代码。）
- 每次 push 附 3 行报告：**做了什么 / 怎么自验的 / 下一步**。禁止声称"已测试"却不给证据。
- 不许动现有舞蹈预览的任何既有行为（播放/三轨/导出/模型库/画幅）；退出游戏模式必须**零残留**（连续进出 10 次不变暗、不降帧、observer 数不变）。
- 不许加：道具/消耗品、技能树、数值成长、每日任务、联机、巨人模式、拍照模式。
- 规范与仓库现实冲突时，以仓库现实为准，并在报告里写明。

## 自验是你的义务，不是选项

沙箱里能跑：`node build.mjs` 打包、`collide.js` 的 Node 单测、无头浏览器真渲染 → 导出 PNG → 逐像素判读（城市在不在、窗有没有亮、影子投没投、她在不在画面里）。**先给我看到画面，再谈手感。**
真机手感与帧率由人验收，但"我看不到画面"不是不做自验的理由。
