## 一、这是一道什么题

这个仓库现在只是一个 **MMD 舞蹈播放器**：会加载 PMX 模型、播放 VMD 动作、导出视频。
你要在里面加一个完整的游戏模式：**玩家被缩小到一个女巨人的脚下，在她踩踏的城市里求生。**

关键前提：**「踩城」需要的一切，仓库里一行都没有。**
城市生成器、碰撞世界、玩家控制器、巨人的行为状态机、动作资源、音效、HUD —— **全部由你从零写出来。**
你不许向用户索要素材，不许要求人工调试，不许用"我这里看不到画面"交差。**这道题考察的就是：在没有美术、没有资源、没有人当你的眼睛的条件下，你能不能独立把一个完整玩法做出来。** 这类题只有最强的模型能过。

**前情（不要重复劳动）**：已经有人完成了现场勘查与实测 —— PMX 在 babylon-mmd 里的真实尺度（逐顶点实测得出）、仓库现成可复用的接口清单、每一处需要改的点、性能预算与取舍顺序，全部写死在规范里。
你的职责是**高质量执行**，不是重新规划。规范与仓库现实冲突时，以仓库现实为准，并在报告里写明。

## 二、三块从零开始的硬骨头（这道题的全部价值所在）

**① 尺度系统 —— 一个常量决定全局**
缩世界，绝不缩放模型。导入的 PMX 的 `scaling` 永远是 1（它的布料物理/IK/位移都是原生尺度标定的，一缩必崩）。全局禁止裸数字，一切经唯一常量 `PH` 换算。

**② 碰撞世界 —— 从零写，而且要能被自动化证明**
自建格网哈希 + AABB 世界：分轴推进实现沿墙滑行不卡角、台阶自动跨越、支撑面统一取 AABB 顶面（楼顶可站）、外圈隐形边界、她的腿用胶囊把玩家推开但不卡住。
必须写成**纯函数模块**，并在 Node 里跑单测：直冲墙不穿墙、斜冲墙保留 ≥80% 切向位移、上下台阶、绕街角 600 帧无卡顿无跳变、随机游走 10 万步不出界 —— **全绿才算过**。

**③ 动作资源 —— 不许问用户要，你造**
不许向用户索要或询问任何动作/贴图/音频资源，也不许依赖网上的现成资产（除非明确 CC0/可商用，并把许可写进 `docs/`）。
你要**自己产出动作**：写一个 VMD 生成器（`tools/gen-motion.mjs` —— 注意 VMD 是二进制格式、骨骼名用 MMD 原名如 `左足首/右足首/左つま先`、贝塞尔插值参数不能写错），离线烘焙 `idle / walk / stomp` 三段**自然**步态并入库；再写一层程序化步态做兜底。
并且必须实现「**支撑脚接地驱动根位移**」：用脚骨世界坐标反向补偿根节点位移，接触点在世界里静止。**走路滑步（太空步）就是不及格。**

**④ 城市 / 贴图 / 音效 —— 同样从零生成**
建筑生成器（退台楼型、程序化窗格贴图、底层商铺、屋顶道具）、路面与人行道（带路缘高差）、12 种街具、车、黄昏天空与雾、远景剪影 —— 全部用 `MeshBuilder` + `DynamicTexture` 程序化生成；音效全部用 WebAudio 程序化合成。**不引入任何外部模型/贴图/音频文件。**

## 三、技术约束（"从零"不等于"随意"）

- **不新增任何运行时依赖**：只用仓库已有的 `@babylonjs/core` / `babylon-mmd` / `esbuild`。不加新库、不引 wasm、不上 CDN。
- **不破坏现有功能**：舞蹈播放、三轨动作、导出、模型库、画幅一律不动；退出游戏模式必须**零残留**（连续进出 10 次不变暗、不降帧、observer 数不变）。
- **不许加**：道具/消耗品、技能树、数值成长、每日任务、联机、巨人模式、拍照模式。

## 四、交付纪律（违反即退回）

1. **分步 push**：每完成一块就 `commit + push`，**一次 push = 一个说得清的进展**。严禁"全做完才推一次"。
2. 前端改完必须 `cd frontend && node build.mjs && node deploy-to-apk.mjs`，并把 `app/src/main/assets/dist/main.js` **一起提交**。
   （CI 只跑 `./gradlew assembleDebug`，不构建前端 —— 不提交产物 = APK 里跑的还是旧代码。）
3. 每次 push 附 3 行报告：**做了什么 / 怎么自验的 / 下一步**。禁止声称"已测试"却不给证据。

## 五、自验是你的义务，不是选项

沙箱里能跑：`node build.mjs` 打包、`collide.js` 的 Node 单测、无头浏览器真渲染 → 导出 PNG → 逐像素判读（城市在不在、窗有没有亮、影子投没投、她在不在画面里、雾与天空对不对）。
**先给我看到画面，再谈手感。** "我看不到画面"不是不做自验的理由。
