## §1 为什么上一版被驳回（不是"没做完"，是"做错了"）

用户亲测 30 分钟后给出的判定是"不能玩"。以下每一条都有**可复现的实测证据**（脚本见 v5.1 文档附录），不是主观感受：

| # | 现象 | 实测根因 |
|---|---|---|
| 1 | 视角只能左右，不能上下 | `player.js:205` 每帧把 `pitch` 拽回 `-0.15`，判定条件是"巨人距离 < 21.7 单位"，而巨人全知永远在附近 → 条件恒真 |
| 2 | 灵敏度低、手感与探索模式完全不同 | 输入被改成"归一化 + 速度式 + 每帧消费 + 4 个滑杆"，量级比既有探索模式慢 5~10 倍 |
| 3 | 房子不接地、大片留白、不精致 | 单栋楼最大边**中位 0.51 单位（9.4 PH）**、高 **4 PH**，街区填充率 **7.8%**（规范要求 ≥60%）；地面贴图 `uvScale=1` 把 248px 摊满 25 单位；城市外无地面 |
| 4 | 天空没做 | 天空球非相机子节点；竖直渐变 V 轴未校验（天顶是地平线橙）；雾密度 0.025 + 亮橙雾色糊掉远景 |
| 5 | 巨人只有腿在动、腿瞬移 | walk 挥臂总幅度 **18°**、上半身 5°；idle 上半身 **0.49°**；关键帧每 5 帧、末段速度是常规段 4~6 倍；`motions.js` 的切换**完全无交叉淡化**（源码注释自认"简化：直接替换"） |
| 6 | 她背对你走路 | 骨骼实测眼骨在**局部 z = −0.47** → 模型脸朝 **−Z**；代码用 `atan2(dx,dz)` 把 **+Z** 对准玩家 |
| 7 | 不追人、原地循环踩 | `approach` 分支**没有任何移动代码**；进入踩踏的阈值 200 PH（10.9 单位）**大于**玩家实际距离 7 单位 → 死循环。7.7 秒遥测：`approach` 一次都没进入，总位移 0.41 单位 |

**另外两处"名义上做了、实际没生效"，属于交付诚信问题：**

- `IS_PC` / `GAME_TARGET` 定义了但全仓库零使用点 → `dist/main.js`、`dist-pc/main.js`、`app/.../dist/main.js` **md5 完全相同**。
- `tools/audit-city.mjs` 的悬空/陷地检查是**恒真**的（`diff = minY - expectedYBase`，同源参数相减永远 0）。**自检造假比不做自检更糟。**

## §2 这个任务难在哪（为什么需要最强模型，而不是能写代码就行）

不是"补几个功能"，是**五个互相耦合的子系统的同时重构**：

1. **输入系统重写**：要把游戏模式从"自制速度式模型"整体退回并复用既有探索模式（`main.js:1210-1228`）的逐帧增量模型，同时保留摇杆/键盘/鼠标三套输入与互斥逻辑，且手感必须与探索模式**数值级一致（同一手势角度差 ≤10%）**。
2. **动画系统重做**：15 个动作、每个动作全身参与（脊柱反扭、摆臂、肘部、肩胛、重心、头部指向），全部由**程序生成的 VMD** 驱动 —— 需要手写逐字节格式（Shift-JIS 骨名、IK 骨、64 字节插值表、四元数顺序）、曲线必须速度连续、关键帧密度≤2 帧、还要与位移速度做**步幅绑定（不许滑步）**。
3. **动画运行时重建**：把"dispose + 直接替换"换成常驻复合动画 + 权重交叉淡化（不能每次重建），并解决异步竞态。
4. **AI 状态机重写**：全知追踪 + 显式位移 + 与动作周期绑定的步频 + 姿态叠加（低头/眼骨/视线调度/表情）在**同一帧内不打架**（一个读骨骼、一个写骨骼，执行顺序错一位就全废）。
5. **城市与渲染重做**：把"大空地上摆小盒子"改成"沿街连续立面 + ≥60% 填充率"，同时把地面贴图、城市外圈地面、天空球跟随、V 轴、雾参数一次性做对，且**多边形预算不能爆**（L1 ≤300k tri、L2 ≤800k tri、60fps）。

**四条硬约束（任何一条破了都算失败）：**

- 参考模型（PMX）**绝不缩放**（scaling 恒为 1）；尺度只通过 `PH` 常量与世界尺寸调整。
- 城市/贴图/音效/动作**全部程序化生成**，不引入任何外部资源文件、不新增依赖。
- 改动**只允许**落在 `frontend/src/game/**` 与 `main.js` 的接入几行；**探索模式（`expXxx`）只读不写**。
- 每一条结论都要能被**无头脚本复现**（沙箱无 GPU）。

## §4 验收门槛（任一不过，整体驳回）

| 维度 | 门槛 |
|---|---|
| 输入 | 同一手势在探索模式与游戏模式下的转角差 **≤10%**；一个灵敏度滑杆 0.2→4 转速单调变化 20 倍 |
| 视角 | 垂直拖拽后松手 1s，pitch 保持 >0.3 rad；静止 5s 不回落 |
| 动作 | `audit-motion.mjs` **15/15 全绿**；任意骨相邻关键帧转角 ≤15°、位移 ≤0.8 单位；切换动作时前后 3 帧内位移 <0.3 单位 |
| 追踩 | 30s 内从 900 PH 外追到 <40 PH；距离单调下降（允许 5% 抖动）；全程朝向夹角 <25° |
| 城市 | 每个商业街区填充率 ≥60%（住宅 ≥45%）；单栋楼 ≥3 段；随机 20 栋截图四件套齐全（门/窗/基座/屋顶设备） |
| 天空/地面 | 抬头：天顶偏蓝、地平偏橙、无接缝；低头：地面纹理可辨；城市外不再出现虚空 |
| 性能 | L1 ≤300k tri 且 60fps（沙箱可达 30fps 即可，真机自测）；L2 ≤800k tri |
| 回归 | `node --test test/*.mjs` 全绿；探索模式功能不受影响 |

3. **禁止重写 git 历史**；在 `62f1e66` 之上增量提交。

6. 不确定的地方**先说明假设**，不要静默选一个实现方式蒙过去。
